# 1.STPE简介

STPE(Single-line Text Processing Engine，单行文本处理引擎)，是一个配置文件解析工具，以单行文本为单位进行处理。以下是其支持的配置文件格式的示例：

```stpe
/// 我是注释
fmt load="14,0;43,0"
fmt atkBuilding="46,${BUILD}"
fmt over="49,0"

param arch="--GATECH 2882 8383 9 63554;--GAWEAP 9393 3939 64844"
fmt team="Taskid=${taskid};AiScript=${aiscript};Sucide=${sucide:yes}"
```



# 2.STPE语法

## 2.1.语法元素

### 2.1.1.配置行

STPE以行为单位解析配置内容，文件中的每行有效文本(非空、非注释、语法正确的文本行)被称为配置行。每个配置行由四个部分组成：

1. 类型标签：作为配置行的一个特殊标记，供用户快速查找某一类配置，同时STPE也提供了一些具有特殊效果的内置类型标签
2. 行名：配置行的名称
3. 等号：等号`=`的作用是加强语义并作为类型标签、行名与配置项列表之间的分隔符
4. 配置项列表：编写在一对引号`""`内的字符串，字符串中有一个或多个配置项，每个配置项使用分号`;`分隔(最后一项可以省略分号)

我们以下方的配置行为例：

```stpe
fmt users="Alice;Bob;Cako;Devil"
```

其中，`fmt`是类型标签；`users`是行名; `=`是分隔符；`"Alice; Bob; Cako; Devil"`则是配置项列表，其中包含四个配置项，分别是`Alice`、`Bob`、`Cako`、`Devil`。



### 2.1.2.类型标签

类型标签用于快速分类某一类配置，加快配置行和配置项的查找速度。除此之外，一些内置的类型标签(例如`param`，`fmt`)会被STPE识别并支持一些特殊处理，例如文本替换和参数解析。



### 2.1.3.配置项列表

配置项列表可以有一个或多个配置项，这些配置项之间都使用`;`分隔，最后一个配置项可以省略分号。在默认情况下，配置项可以使用除分号和引号以外的任何Unicode字符，STPE会严格按照分号为界限分隔每个配置项，及时是配置项两侧的空格也会保留(可以通过设置STPE去除)。如果配置项内必须要使用分号或引号，可以使用转移字符`\`将其转义，例如`\"`和`\;`。以下是配置项的示例：

```stpe
"a;b;c;d"  ///四个配置项：`a`、`b`、`c`、`d`
"ab ;cd " ///两个配置项：`ab `、`cd `
"a\;;b\;" //两个配置项：`a;`、`b;`
```



### 2.1.4.注释

注释以连续的三个斜杠开头`///`，可以独占一行，也可以附加在配置行的末尾(即最后一个`"`之后)。以下都是正确的注释：

```stpe
/// 我是注释
fmt desc="Your configuration." /// 我也是注释
```



## 2.2.内置类型标签

#### param

如果配置行的类型标签是`param`，则STPE会将配置项列表先分解为单个的配置项，然后再将每个配置项按命令行参数格式分解为参数名和参数值，例如对于下方的配置行：

```stpe
param options="--Alpha a b;--Delta 90"
```

STPE会先将其分解为配置项：`--Alpha a b`和`--Delta 90`，然后再进一步分解为命令行参数：

1. 参数名：`Alhpa`，参数值：`a`、`b`
2. 参数名：`Delta`，参数值：`90`

参数名要求使用`--`开头，参数名和参数值之间使用空格分隔。



#### fmt

如果配置行的类型标签是`fmt`，则STPE允许我们在配置项中使用插值表达式`${placeholder}`进行占位，其中`placeholder`是占位符名称，后期可以通过API将占位符对应的插值表达式替换为实际的字符串，例如对于下方的配置行：

```
fmt insert="My name is ${name}"
```

后期我们可以通过`foo.replace("name", "Bob")`的方式将`${name}`替换为`"Bob"`，最终结果为`"My name is Bob"`。

除此之外，fmt还支持在插值表达式中设置默认值，默认值使用冒号`:`与占位符分隔，例如`${name:Bob}`。在程序中，如果我们正在获取一个配置项的字符串形式，并且没有将所有的插值表达式替换为实际的字符串时，可能发生以下两种情况之一：

1. 插值表达式有默认值时，使用默认值替换插值表达式
2. 插值表达式没有默认值时，向外界提示错误



## 2.3.命名规则

命名规则如下：

* 类型标签：除`"`、`=`、空格以外的任何可见的Unicode字符
* 行名：除`"`、`=`、空格以外的任何可见的Unicode字符
* 配置项列表：除`"`，`;`、换行符以外的任意可见的Unicode字符(可以使用转义字符`\`对特殊字符转义)
